# HR-B - Kevalon Technology Recruitment CRM (Backend)

Node.js + Express + MongoDB Backend REST API for Kevalon Technology Recruitment CRM.

## Features
- JWT Authentication & Dynamic RBAC Middleware
- Smart Auto-Assignment Candidate Engine
- Multi-Stage Interview Workstation Logic (Technical 10 Random Questions, Practical 2 Tasks, HR Evaluation)
- Complete Controller-Service-Model Architecture
- Event-Based Notification Dispatcher & Audit Log System
- Database Seeder with Default Credentials & Sample Data
